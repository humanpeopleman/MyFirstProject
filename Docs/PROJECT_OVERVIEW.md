# Unity Survival Game --- Project Overview

## 1. 프로젝트 목적

Unity와 C#으로 탑다운 2D 서바이벌 게임을 완성한다. 단순히 기능을 많이
추가하는 것보다 작은 범위의 게임을 끝까지 완성하고, 개발 과정과 설계
의도를 포트폴리오로 설명할 수 있도록 하는 것이 우선이다.

## 2. 현재 프로젝트 정보

-   엔진: Unity
-   언어: C#
-   장르: 2D 탑다운 서바이벌
-   GitHub: `humanpeopleman/MyFirstProject`
-   기준 브랜치: `main`
-   현재 확인된 핵심 스크립트: `PlayerController`, `PlayerHealth`,
    `PlayerAttack`, `EnemyController`, `EnemyHealth`

## 3. 핵심 게임 루프

1.  플레이어가 적을 피하고 공격한다.
2.  적이 플레이어를 추적하고 접촉 시 피해를 준다.
3.  적을 처치하면 경험치 아이템이 생성된다.
4.  플레이어가 경험치를 획득해 레벨업한다.
5.  레벨업 시 능력 강화를 선택한다.
6.  생존 시간이 길어질수록 적의 수 또는 생성 빈도가 증가한다.
7.  플레이어가 사망하면 게임 오버 및 재시작이 가능하다.

## 4. 완료 기준 (MVP)

-   플레이어 이동과 공격이 정상 작동한다.
-   적이 플레이어를 추적하고 피해를 준다.
-   적 처치와 플레이어 사망이 정상 처리된다.
-   적 생성 시스템이 작동한다.
-   경험치 획득 및 레벨업이 작동한다.
-   최소 2\~3개의 강화 선택지가 존재한다.
-   체력, 경험치, 레벨, 생존 시간이 UI에 표시된다.
-   게임 오버 화면에서 재시작할 수 있다.
-   빌드 후 처음부터 끝까지 플레이 가능하다.

## 5. 범위 관리 원칙

MVP가 완성되기 전에는 온라인 기능, 복잡한 인벤토리, 다수의 캐릭터,
대규모 맵 등 핵심 게임 루프와 직접 관련 없는 기능을 추가하지 않는다. 새
아이디어는 `TODO.md`의 보류 항목에 기록하고, 현재 작업을 마친 뒤
우선순위를 다시 판단한다.

## 6. 현재 상태

마지막으로 확인한 GitHub 코드에는 아래 5개 스크립트가 존재한다. -
`PlayerController.cs`: 입력 기반 이동, 마지막 이동 방향 보관,
Rigidbody2D 이동 - `PlayerHealth.cs`: 체력 초기화, 적 접촉 피해, 사망
플래그 - `PlayerAttack.cs`: 마지막 이동 방향 기준 공격 위치 계산,
OverlapCircle 공격, 쿨타임 - `EnemyController.cs`: Player 태그 대상 탐색
및 추적 이동 - `EnemyHealth.cs`: 체력, 피해 처리, 체력 0일 때 오브젝트
파괴

주의: GitHub의 마지막 커밋과 로컬 작업 트리가 다를 수 있다. 작업을
이어갈 때 현재 브랜치와 미커밋 변경 사항을 먼저 확인한다.
